# Project agent instructions

Read `docs/COMP5521_HTLC_Project_2026.pdf` before changing project scope.
For acceptance decisions, use `.agent/acceptance.md`; for responsibilities
and handoffs, use `docs/collaboration.md`.

The course permits AI assistance only for individual functions or debugging.
Do not generate an entire graded component (contracts, cross-chain protocol,
frontend or report). Mark AI-assisted code at the assisted function and
record the exact function and assistance in the PR and final report. Leave
implementation and live assessment to the students.

Keep Ethereum Sepolia MST and Arbitrum Sepolia native ETH independent;
coordinate off-chain. For every implementation PR, show the applicable
acceptance item, meaningful positive/negative test evidence, and any
remaining gaps. Confirm the team's architecture choice before adding
third-party toolchain configuration, inspect defaults at pinned versions,
and keep diffs minimal.
